= DNS interne du vRack — Spécification
:toc: left
:icons: font
:status: PLAN — décisions actées le 16 juin 2026

[abstract]
DNS privé pour le réseau vRack : chaque hôte joignable par
`<nom>.vrack.quimeo.net` → son IP vRack `192.168.42.x`, **sans table de hosts
à maintenir** (beryl génère la zone depuis les configs). Privé : résolveur
exposé UNIQUEMENT sur le vRack ; depuis le poste opérateur (macOS), accès
via un tunnel **SSH (clé)**.

== 1. Objectifs

. Joindre les hôtes par **nom** (`ssh pkg`, `https://pkg.vrack.quimeo.net`,
  Capistrano) au lieu d'IP vRack codées en dur.
. **Zéro maintenance manuelle** : la zone DÉRIVE des `vrack-interface: { ip }`
  des `host.yml` (source de vérité unique).
. **Privé** : le résolveur n'écoute que sur le vRack ; rien de public.
. **Accès opérateur (Mac) gated par la clé SSH** uniquement.

== 2. Architecture

[source]
----
  host.yml (vrack-interface: { ip })  ──beryl vrack-dns──▶  zone local-data
                                                                  │
                          ┌──────────────── unbound sur 1-2 z ◀───┘
                          │   (écoute IP vRack, zone vrack.quimeo.net,
                          │    forward le reste vers résolveurs publics)
        ┌─────────────────┴───────────────┐
        ▼ (resolv.conf → z, search)        ▼ (sshuttle -r <z> 192.168.42.0/24 --dns)
   serveurs du vRack                    poste opérateur (macOS)
   ssh pkg / curl https://pkg/…         ssh pkg.vrack.quimeo.net / curl …
----

=== 2.1 Résolveur (serveurs)
* **`unbound`** (base FreeBSD, rien à compiler) sur **1-2 bastions `z`**
  (toujours up, rôle infra ; redondance des résolveurs = pas de SPOF).
* Écoute **sur l'IP vRack** du z (`interface: 192.168.42.x`), `access-control`
  limité à `192.168.42.0/24` → jamais joignable publiquement.
* Zone `vrack.quimeo.net` servie en **`local-data`** ; le reste forwardé
  (résolveurs publics) pour que les serveurs résolvent aussi Internet.

=== 2.2 Génération de la zone (beryl)
* Commande **`beryl vrack-dns`** : lit l'IP vRack de TOUS les hosts
  (`vrack-interface`), produit les `local-data` (`<nom>.vrack.quimeo.net.
  IN A 192.168.42.x` + PTR), pose le fichier sur les z et **recharge unbound**.
* Idempotent ; régénérable à chaque ajout d'hôte.

=== 2.3 Côté serveurs (clients du résolveur)
* Recette **`resolver-vrack`** : `resolv.conf` → `nameserver <IP vRack z1/z2>`
  + `search vrack.quimeo.net` → `ssh pkg` suffit.

=== 2.4 Côté poste opérateur (macOS) — accès clé-SSH-only
* **`sshuttle`** : `sshuttle -r admin@<z>.quimeo.net 192.168.42.0/24 --dns`
  → route le subnet vRack **et le DNS** à travers une session **SSH (clé)**.
* « Privé + clé SSH » par construction : tout transite par le tunnel SSH vers
  un z, rien d'exposé.
* **Limite** : sshuttle tunnelise **TCP + DNS** (donc `ssh`/`curl`/repo par
  nom OK), **pas l'ICMP** → le `ping` littéral ne répond pas (besoin réel =
  ssh/repo, pas ping). Un VPN tun complet serait nécessaire pour l'ICMP —
  hors périmètre (et pas « clé SSH »).
* Option : `beryl` génère un script `vrack-up` (le bon z + subnet).

== 3. Intégration beryl (à écrire)
. Commande **`beryl vrack-dns`** (génère + déploie la zone sur les z).
. Recette **`unbound-vrack`** (installe/configure unbound sur un z).
. Recette **`resolver-vrack`** (pointe un serveur vers les résolveurs z).
. (option) Génération du script `vrack-up` côté opérateur.

== 4. Sécurité
* Résolveur **non public** (bind IP vRack + access-control 192.168.42.0/24).
* Accès opérateur **uniquement via SSH (clé)** (sshuttle), pas de port DNS exposé.
* La zone ne contient que des IP privées (192.168.42.x) → aucune fuite utile
  même si elle transitait.

== 5. Phasage
[cols="1,4"]
|===
| Étape | Action
| 1 | Recette `unbound-vrack` → unbound sur z1 (puis z2 pour la redondance).
| 2 | Commande `beryl vrack-dns` → génère la zone depuis les configs, déploie, recharge.
| 3 | Recette `resolver-vrack` → les serveurs pointent vers z1/z2 + search.
| 4 | Script `vrack-up` (sshuttle) côté Mac → `ssh pkg.vrack.quimeo.net` depuis le poste.
| 5 | Bascule des URL (dépôt pkg, Capistrano, Tang) vers les noms `*.vrack.quimeo.net`.
|===
